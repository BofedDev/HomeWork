Homework #39  -------------

Створіть компонент Definitions.jsx, який повертає структуру:
<!-- Результатом выполнения вашего кода должен быть следующий вывод: -->

<dl>
    <dt>one</dt>
    <dd>two</dd>
    <dt>another term</dt>
    <dd>another description</dd>
</dl>

Усі компоненти у цьому завданні повинні бути функціональними.
Компонент отримує дані через пропс — дані лежать у наданому масиві
const definitions = [
{ dt: 'one', dd: 'two', id: 1 },
{ dt: 'another term', dd: 'another description', id: 2 },
];

<DefinitionsList data={definitions} />;
Необхідно прийняти цей пропс у компоненті та відрендерити отримані дані відповідно до заданої HTML-структури.
Підключіть компонент Definitions у App.js і відрендерте його.
Не забувайте про пропс key при рендері списків елементів.
